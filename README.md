# BasharSoft Events Portfolio

The 2025–2026 BasharSoft events portfolio, built as a static website: event results, FORASNA audience insights, a production library, digital experiences and recap videos.

## View locally
Open `index.html` in a browser, or run a local server:

    python3 -m http.server 8000

## Publish with GitHub Pages
In the repository, go to Settings → Pages, set Source to "Deploy from a branch", pick `main` and `/ (root)`, and save.
